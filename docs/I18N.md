# I18N.md — Internationalization & Translation

> Panduan bagaimana CV-Buff handle multi-bahasa dan cara nambah locale baru.

---

## 🌍 Locales yang Didukung

| Code | Bahasa | Status |
|---|---|---|
| `id` | Bahasa Indonesia | **Default** ✅ |
| `en` | English | ✅ |

User bisa switch via:
- URL: `/id/...` atau `/en/...`
- Cookie `NEXT_LOCALE` (auto set saat user switch)
- Dropdown di header landing page

```
src/i18n/
├── config.ts                 ← Definisi locales + default
├── runtime.ts                 ← Helper browser (getPreferredLocale, isSupportedLocale)

├── request.ts                 ← Server-side init
├── routing.public.ts          ← Routing config
├── locales/
│   ├── id.json                ← Translasi Indonesia (default, ~820 keys)

    ├── client.ts              ← Hooks: useTranslations, useLocale
    ├── server.ts              ← Server: getTranslations, getMessages
    ├── utils.ts               ← createTranslator helper
    └── *.ts                   ← Internal utilities
```

## 🛠️ Cara Pakai di Komponen

### Client Component (React Component)

```tsx
import { useTranslations } from "@/i18n/compat/client";

function MyComponent() {
  const t = useTranslations("dashboard.resumes");
  // namespace = "dashboard.resumes"

  return (
    <div>
      <h1>{t("myResume")}</h1>           {/* dashboard.resumes.myResume */}
      <button>{t("create")}</button>      {/* dashboard.resumes.create */}
    </div>
  );
}
```

### Dengan Interpolasi

```tsx
const t = useTranslations("grammarCheck");

<p>{t("description", { count: 5 })}</p>
// jika `description` = "Ditemukan {count} saran" → "Ditemukan 5 saran"
```

### Server Component / Route Handler

```tsx
import { getTranslations } from "@/i18n/compat/server";

export async function generateMetadata({ params: { locale } }) {
  const t = await getTranslations({ locale, namespace: "common" });
  return {
    title: t("title") + " - " + t("subtitle"),
  };
}
```

### Get Current Locale

```tsx
import { useLocale } from "@/i18n/compat/client";

function MyComponent() {
  const locale = useLocale();   // "id" | "en"
  return <div>Active locale: {locale}</div>;
}
```

## 📝 Struktur Translation File

File `id.json` dan `en.json` punya struktur **identik** — sama persis key hierarchy. Beda hanya value.

```json
{
  "common": {
    "title": "CV-Buff",
    "subtitle": "Editor CV Berbasis AI"
  },
  "home": {
    "header": {
      "title": "CV-Buff",
      "startButton": "Mulai"
    },
    "hero": {
      "badge": "Pembuatan CV Cerdas",
      "title": "Buat CV Anda Lebih Mudah dan Cerdas"
    },
    "faq": {
      "items": [
        {
          "question": "Apakah CV-Buff gratis?",
          "answer": "Ya, gratis untuk personal."
        }
      ]
    }
  },
  "dashboard": {
    "sidebar": { ... },
    "resumes": { ... },
    "settings": { ... }
  },
  "workbench": {
    "sidePanel": { ... },
    "basicPanel": { ... }
  }
}
```

### Naming Convention

- **Namespace**: domain-level (`common`, `home`, `dashboard`, `workbench`, `pdfExport`, `field`, dll.)
- **Key**: camelCase (`createResume`, `myResume`, `selectFolder`)
- **Nested**: max 3-4 level dalam, jangan terlalu dalam

### Aturan

1. **Struktur identik** di kedua file (id + en) — script pengecekan:
   ```bash
   # Cek key di id.json tapi tidak di en.json
   diff <(jq -r 'paths(scalars) | join(".")' src/i18n/locales/id.json | sort) \
        <(jq -r 'paths(scalars) | join(".")' src/i18n/locales/en.json | sort)
   ```

2. **JANGAN hardcode** user-facing string di komponen. Selalu lewat `t()`.

3. **Plural / interpolasi**: pakai `{varName}`:
   ```json
   "description": "Found {count} suggestions"
   ```

4. **HTML/Markdown** dalam value: pakai sparingly. Lebih aman pakai komponen React + `t()` untuk text segments.

## ➕ Cara Nambah Locale Baru

Contoh: tambah **Spanish (`es`)**.

### Step 1: Edit `src/i18n/config.ts`

```ts
export const locales = ["id", "en", "es"] as const;
export type Locale = (typeof locales)[number];

export const defaultLocale: Locale = "id";  // tetap

export const localeNames: Record<Locale, string> = {
  id: "Bahasa Indonesia",
  en: "English",
  es: "Español",     // NEW
};
```

### Step 2: Buat `src/i18n/locales/es.json`

Copy `en.json` sebagai template:

```bash
cp src/i18n/locales/en.json src/i18n/locales/es.json
```

Lalu translate semua value (pertahankan struktur key).

### Step 3: Daftarkan di `src/i18n/compat/server.ts`

```ts
import idMessages from "@/i18n/locales/id.json";
import enMessages from "@/i18n/locales/en.json";
import esMessages from "@/i18n/locales/es.json";   // NEW

const MESSAGES: Record<Locale, Messages> = {
  id: idMessages as Messages,
  en: enMessages as Messages,
  es: esMessages as Messages,                       // NEW
};
```

### Step 4: Daftarkan di `src/routes/__root.tsx`

```tsx
import idMessages from "@/i18n/locales/id.json";
import enMessages from "@/i18n/locales/en.json";
import esMessages from "@/i18n/locales/es.json";   // NEW

function RootComponent() {
  const locale = getPreferredLocale(pathname);
  const messages =
    locale === "en" ? enMessages :
    locale === "es" ? esMessages :                  // NEW
    idMessages;

  // ...
}
```

### Step 5: Update Sample Data (opsional)

Bila ingin sample CV persona-spesifik untuk locale baru, edit `src/config/initialResumeData.ts`:

```ts
export const initialResumeStateEs = { /* persona Spanyol */ };
```

Dan logic switching di `useResumeStore.createResume()`.

### Step 6: Update Sitemap

`src/app/sitemap.ts`:

```ts
const routes = ["id", "en", "es"];
```

`public/sitemap.xml`:

```xml
<url>
  <loc>https://cv.agentbuff.id/es</loc>
  ...
</url>
```

### Step 7: Build & Test

```bash
pnpm build
pnpm dev
# Buka http://localhost:1713/es
```

## 🔧 Translation Tools

### Manual Translation

Karena file JSON dengan struktur identik, mudah di-diff dan translate manual.

### AI-Assisted Translation

Untuk add locale baru cepat:

1. Copy `en.json` → `<new-locale>.json`
2. Paste ke ChatGPT/Claude dengan prompt:
   > "Translate all string VALUES in this JSON file to Spanish, while preserving the structure and keys exactly. Don't translate variable placeholders like `{count}` or `{title}`. Don't translate technical terms like 'PDF', 'JSON', 'Markdown', 'API'."
3. Save result ke `<new-locale>.json`
4. Review manual (AI translation usually 90% benar, polish dengan native speaker)

### Crowdsource Translation

Setup di platform seperti **Crowdin** atau **Lokalise**:
1. Upload `id.json` & `en.json` sebagai source
2. Invite community translators
3. Auto-sync via API

## 🌐 Date / Number Formatting

Pakai `Intl` API:

```tsx
import { formatDateString } from "@/lib/utils";
import { useLocale } from "@/i18n/compat/client";

function MyComponent({ date }) {
  const locale = useLocale();
  return <span>{formatDateString(date, locale)}</span>;
}
```

`formatDateString` defaults ke `id` jika locale tidak dispecify.

Untuk number:

```tsx
const n = new Intl.NumberFormat(locale).format(1234567);
// "1.234.567" untuk id, "1,234,567" untuk en
```

## 🕒 Time Zone

CV-Buff hardcoded ke **`Asia/Jakarta`** untuk semua operasi temporal di `src/routes/__root.tsx`:

```tsx
<NextIntlClientProvider locale={locale} messages={messages} timeZone="Asia/Jakarta">
```

Jika perlu support multi-timezone, ubah ini menjadi dinamis berdasarkan user preference.

## 🔍 Debugging i18n

### Missing key

Pesan `MISSING_MESSAGE: Could not resolve <key> in messages for locale "id"`:
- Cek typo di `t("nama-key")`
- Cek struktur namespace match
- Cek `id.json` punya key tersebut

### Key di id.json tapi tidak di en.json (atau sebaliknya)

```bash
# Bandingkan paths
diff <(jq -r '. | paths(scalars) | join(".")' src/i18n/locales/id.json | sort) \
     <(jq -r '. | paths(scalars) | join(".")' src/i18n/locales/en.json | sort)
```

### Locale tidak switch

- Cek cookie `NEXT_LOCALE` di DevTools → Application → Cookies
- Cek URL pattern: harus `/id/...` atau `/en/...`
- Cek `getPreferredLocale(pathname)` return value

### Plural form salah

Compat layer kita support placeholder simple (`{count}`), tapi tidak full ICU MessageFormat. Untuk plural complex (zero/one/few/many), butuh upgrade library.
