## 💡 Kenapa CV-Buff?

Pernahkah Anda merasa…

- 😩 Capek bayar bulanan ke Canva / Resume.io cuma untuk download PDF satu kali?
- 😟 Khawatir CV Anda — yang isinya **gaji harapan, alamat rumah, nomor HP** — tersimpan di server orang asing?
- 😤 Frustrasi karena template gratisan terlihat seperti dibuat tahun 2008?
- 🤔 Bingung kalimat lamaran Anda **"profesional gak sih?"**, tapi tidak ada yang bisa cek?

**CV-Buff dibuat tepat untuk Anda.**

CV-Buff adalah editor CV open-source generasi baru yang menggabungkan **kecerdasan AI** dengan **prinsip privasi mutlak**. Tidak ada server kami yang menyentuh data Anda. Tidak ada akun untuk dibuat. Tidak ada langganan untuk dibayar. Anda mengetik, AI menyempurnakan, browser merender, lalu CV PDF Anda jadi.

Sesederhana itu.

## 🌟 Yang Bikin CV-Buff Beda

### 🔒 **Privasi-Pertama Bukan Sekadar Slogan**

Semua data CV Anda — nama, email, riwayat pekerjaan, gaji, sertifikat — disimpan **100% di browser Anda sendiri** menggunakan LocalStorage + IndexedDB. Server kami **tidak pernah** melihat, menyimpan, atau menganalisis isinya. Bahkan ketika Anda pakai fitur AI, kunci API milik Anda sendiri yang dipakai — bukan kuota gratis terbatas yang bisa kami panen datanya.

> *"Data CV Anda lebih aman daripada di Google Drive. Beneran."*

### 🤖 **AI yang Bisa Anda Pilih Sendiri**

Bosan vendor lock-in? CV-Buff mendukung **provider AI apa pun**:

- **OpenAI** (GPT-4o, GPT-4o-mini, o1)
- **Anthropic Claude** (Sonnet 4.6, Opus 4.7, Haiku 4.5)
- **Google Gemini** (Flash, Pro)
- **Provider Custom** apa saja: Groq, OpenRouter, Together AI, Mistral, Perplexity, atau **LLM lokal** Anda sendiri (Ollama, LM Studio)

Tinggal masukkan endpoint, pilih protokol (OpenAI-compatible / Anthropic / Gemini), tempel API key — dan AI siap memoles CV Anda.

### 🎨 **8 Template yang Sudah Lulus Audit Recruiter**

Setiap template dirancang untuk lolos **ATS (Applicant Tracking System)** dan tetap memikat mata HR manusia. Bukan template generik dari tahun 2015.

### ⚡ **Editor 3-Panel Real-Time WYSIWYG**

Sebelah kiri: panel layout & gaya. Tengah: form editor sections. Kanan: preview A4 yang ter-update **per ketikan**. Apa yang Anda lihat = apa yang Anda dapatkan. Auto-save tiap 1.5 detik. Tidak ada tombol "save" yang harus diingat.

### 📤 **Ekspor ke 4 Format Sekaligus**

| Format | Untuk apa? |
|--------|------------|
| **PDF Server-Side** | Render presisi tinggi via Puppeteer — 100% akurat untuk lamaran formal |
| **Browser Print** | Cadangan via `Cmd/Ctrl + P` → Save as PDF, plus fine-tune margin manual |
| **JSON Config** | Backup CV Anda; bisa di-import ulang di komputer lain dalam 1 klik |
| **Markdown** | Copy-paste cepat ke ChatGPT untuk minta saran lanjutan |

### 💾 **Sinkronisasi Lokal Lewat File System Access API**

Pilih satu folder di komputer Anda. CV-Buff otomatis menyimpan setiap CV sebagai file `.json` di folder itu (debounced setiap 1.5 detik). Backup naturalpada Dropbox, OneDrive, iCloud, atau Git pribadi Anda — tanpa cloud kami sama sekali.

## 🤖 Pakai AI Favorit Anda — Apa Pun Itu

CV-Buff punya **3 fitur AI** yang berjalan di atas provider pilihan Anda:

### ✍️ **AI Polish** — Sempurnakan teks satu klik

Sorot teks deskripsi pengalaman Anda → tombol AI Polish → teks yang kaku berubah menjadi kalimat profesional dengan kata kerja aktif, metrik yang menonjol, dan struktur yang cocok untuk recruiter.

> Sebelum: *"Saya bertanggung jawab membuat fitur baru di aplikasi."*
>
> Sesudah: *"Memimpin pengembangan fitur dashboard analitik baru, meningkatkan retensi pengguna 23% dalam Q2 dan mengurangi churn rate sebesar 8%."*

Anda bahkan bisa kasih instruksi tambahan: *"pakai bahasa formal tapi tidak kaku, tonjolkan metrik angka"*.

### 📝 **AI Grammar Check** — Pemeriksa typo & tanda baca

AI memindai CV Anda dan menandai (highlight visual di preview) setiap typo, tanda baca berlebih, dan kesalahan kecil yang biasanya luput dari mata Anda sendiri. Setiap saran bisa diterima atau ditolak satu per satu.

### 📥 **PDF Resume Import** — Punya CV lama? Tinggal upload

Drag-drop file PDF CV lama Anda → AI Vision (Gemini) mengekstrak struktur (basic info, education, experience, projects, skills) → otomatis mengisi semua field di CV-Buff. Dari file mati menjadi CV yang bisa diedit ulang dalam 30 detik.

### 🔌 **Sistem Provider Generik**

Buka `/dashboard/ai`, klik **"+ Tambah Provider Custom"**, isi form 3-field:

```
Nama Provider:  Groq Llama 3.3
Protokol:       OpenAI Compatible
Endpoint:       https://api.groq.com/openai/v1
Model ID:       llama-3.3-70b-versatile
API Key:        gsk_...
```

Selesai. Provider siap dipakai untuk Polish & Grammar Check. Mau pakai Ollama lokal? Ganti endpoint ke `http://localhost:11434/v1` — beres.

## 🚀 Mulai Dalam 30 Detik

### Online (segera)

Kunjungi **[cv.agentbuff.id](https://cv.agentbuff.id)** dan langsung bikin CV. Tidak perlu install apa-apa.

### Self-Host (untuk privasi maksimal)

```bash
git clone https://github.com/nugrahalabib/CV-Buff.git
cd CV-Buff
pnpm install
pnpm dev
```

Buka [http://localhost:1713](http://localhost:1713) — Anda sudah punya editor CV pribadi yang berjalan di mesin sendiri. **Selesai.**

> Butuh `Node.js 20+` dan `pnpm 10+`. Kalau belum punya pnpm: `npm i -g pnpm`.

### Production Build

```bash
pnpm build      # bundling production ke ./dist/
pnpm start      # serve build via Node HTTP server di port 1713
```

## 📦 Deploy ke Mana Saja

CV-Buff dirancang untuk deploy di banyak platform:

### 🐳 Docker (paling simpel)

```bash
docker compose up -d
```

Container siap di port 1713. Multi-stage build, image akhir <200MB.

### ☁️ Cloudflare Workers

```bash
pnpm build
pnpm wrangler deploy
```

### 🌐 Vercel / Netlify / Railway / Render

`pnpm build` lalu point ke `dist/server/server.js` (Node) atau `dist/client/` (static). Server entry tersedia di `server.mjs`.

### 🔧 Manual VPS

```bash
pnpm build
PORT=1713 node server.mjs
```

## 🛠️ Dibangun di Atas Pondasi Kuat

| Layer | Teknologi | Alasan |
|-------|-----------|--------|
| **Meta-framework** | TanStack Start + Vite 7 | File-based routing, SSR-ready, build cepat |
| **UI** | React 18 + TypeScript 5 + Tailwind 3.4 | Type-safe, ergonomis, gampang di-customize |
| **State** | Zustand 4 + persist middleware | Sederhana, predictable, no boilerplate |
| **Komponen** | shadcn/ui + HeroUI + Radix primitives | Aksesibilitas built-in, gak perlu re-invent |
| **Editor** | Tiptap 3 (bullet list, color, link, alignment) | Rich text yang bisa di-extend |
| **Animasi** | Framer Motion 11 | Smooth seperti Apple |
| **PDF** | Puppeteer + Sparticuz Chromium | Render presisi tinggi di server-less |
| **i18n** | Custom compat layer (next-intl style) | Bahasa Indonesia (default) + English |
| **Storage** | LocalStorage (Zustand persist) + IndexedDB (file handles) | 100% client-side |

```bash

pnpm dev          # test lokal
pnpm build        # pastikan production build pass
```

### 🌍 Terjemahan

Bisa bahasa Mandarin, Spanyol, Jepang, Arab? Tambahkan locale baru di `src/i18n/locales/` dan daftarkan di `src/i18n/config.ts`. Lihat `id.json` sebagai referensi struktur.

Bikin template baru? Lihat `src/components/templates/` — tinggal copy folder template yang sudah ada, ubah `config.ts` (warna, spacing) dan `sections/*.tsx` (layout). Daftarkan di `src/components/templates/registry.ts` dan template otomatis muncul di gallery.

## 📚 FAQ Singkat

**Q: Apakah CV saya benar-benar tidak terkirim ke server?**
A: Ya. Semua disimpan di LocalStorage browser Anda. Cek `DevTools → Application → Local Storage` — Anda lihat semuanya tersimpan di mesin sendiri. Network tab kosong saat Anda ngetik.

**Q: Kalau cache browser kena clear, CV saya hilang?**
A: Bisa. Karena itu kami sediakan fitur **Sinkronisasi Folder Lokal** di Settings — setiap CV otomatis ke-backup ke folder yang Anda pilih (cocok kalau folder itu di Dropbox/OneDrive/iCloud/Git).

**Q: Saya tidak punya API key OpenAI. Bisa pakai CV-Buff?**
A: Bisa. Editor, template, ekspor PDF — semuanya jalan tanpa AI. Fitur AI (polish, grammar, PDF import) **opsional**. Atau pakai Google Gemini yang punya free tier generous.

**Q: Bisa untuk lamaran kerja di luar negeri?**
A: Bisa banget. Switch ke locale `en`, isi sample data dengan persona Anda — selesai.

**Q: Browser apa yang direkomendasikan?**
A: Chrome / Edge (Chromium) untuk pengalaman terbaik (terutama untuk fitur Sync Folder yang butuh File System Access API). Firefox & Safari bisa untuk editor + ekspor PDF, tapi Sync Folder tidak tersedia.

**Q: Apakah PDF dari CV-Buff lulus ATS?**
A: Ya. Template Klasik, Dua Kolom, Minimalis, Elegan, dan Latar Judul didesain ATS-friendly. Untuk lamaran formal ke perusahaan besar, kami sarankan template Klasik atau Minimalis.
